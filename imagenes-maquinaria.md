## 🔧 Pasos para Instalar las Imágenes:

### Paso 1: Descargar las Imágenes
1. Ve a **Google Images**
2. Busca cada término indicado arriba
3. Selecciona **"Herramientas" → "Tamaño → Grande"**
4. Filtra por **"Tipo → JPG"**
5. Descarga las imágenes y renombra según los nombres de archivo

### Paso 2: Optimizar las Imágenes (Opcional)
- Usa **TinyPNG.com** para reducir tamaño sin perder calidad
- O usa **Photoshop/GIMP** para ajustar a 800x600px

### Paso 3: Colocar en la Carpeta
- Guarda todas las imágenes en: `c:\Users\pc\Desktop\TODO EN ASFALTO DE LEON\`

### Paso 4: Actualizar el Código
Ejecuta este comando para reemplazar los placeholders:

```bash
# Reemplazar placeholders con imágenes reales
powershell -Command "(Get-Content index.html) -replace '<span>🚛</span>', '<img src=\"extendedora-asfalto.jpg\" alt=\"Extendedora de Asfalto\" class=\"machinery-img\">' | Set-Content index.html"
```

## 🎯 Consejos para Buenas Imágenes:
- ✅ **Maquinaria amarilla/naranja** (colores de construcción)
- ✅ **En acción** (trabajando en carreteras)
- ✅ **Buen día** (luz natural, sin lluvia)
- ✅ **Sin personas** o personas con equipo de seguridad
- ✅ **Alta resolución** (mínimo 800px ancho)
