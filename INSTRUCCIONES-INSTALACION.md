# 📦 TODO EN ASFALTO DE LEÓN - Guía de Instalación

## 🚀 Opciones de Acceso

### 1. **Versión Local (Actual)**
- **URL**: `http://localhost:3000`
- **Requiere**: Servidor local corriendo
- **Instalación**: PWA directa desde Chrome

### 2. **Versión para Subir a Hosting**
Si quieres subir a tu propio dominio:

#### 📁 **Archivos Necesarios:**
```
📂 TODO EN ASFALTO DE LEON/
├── 📄 index.html (página principal)
├── 🎨 style.css (estilos responsive)
├── ⚡ script.js (funcionalidades PWA)
├── 📱 manifest.json (configuración PWA)
├── 🔧 sw.js (service worker offline)
├── 🖼️ Cesar.png (imagen propietario)
├── 🎯 icon-192x192.svg (icono PWA)
├── 🎯 icon-512x512.svg (icono HD)
├── 📋 browserconfig.xml (config Windows)
└── 📖 README-PWA.md (guía usuario)
```

#### 🌐 **Pasos para Subir a Hosting:**

1. **Compra un dominio** (ej: todoenasfaltoleon.com)
2. **Contrata hosting** compatible con HTTPS
3. **Sube todos los archivos** a la carpeta principal
4. **Configura SSL/TLS** (certificado HTTPS - obligatorio para PWA)
5. **Verifica** que todos los archivos sean accesibles

#### 🔧 **Hosting Recomendados:**
- **Gratis**: GitHub Pages, Netlify, Vercel, Firebase Hosting
- **Pago**: Hostinger, SiteGround, Bluehost, GoDaddy

## 📱 Instalación como App Android

### Desde Chrome (Recomendado):
1. Abre tu dominio en Chrome Android
2. Menu (⋮) → "Instalar aplicación"
3. Confirma → ¡Listo!

### Características PWA:
- ✅ Funciona offline básicamente
- ✅ Icono en pantalla de inicio
- ✅ Sin barra de direcciones
- ✅ Notificaciones del sistema
- ✅ Actualizaciones automáticas

## 🔒 Requisitos Técnicos

### Para PWA Completa:
- ✅ **HTTPS obligatorio** (SSL/TLS)
- ✅ Dominio propio
- ✅ Todos los archivos accesibles
- ✅ Service Worker registrado

### Para Versión Local:
- ✅ Servidor local corriendo
- ✅ Acceso desde mismo red WiFi
- ✅ Chrome en Android
