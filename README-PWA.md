# 📱 Instalar TODO EN ASFALTO DE LEÓN como App en Android

## 🚀 Pasos para Instalar la PWA (Progressive Web App)

### Método 1: Desde Chrome (Recomendado)
1. Abre **Chrome** en tu dispositivo Android
2. Visita: `http://localhost:3000` (o tu dominio cuando esté en producción)
3. Espera a que cargue completamente la página
4. Toca el **menú de tres puntos** (⋮) en la esquina superior derecha
5. Selecciona **"Instalar aplicación"** o **"Añadir a pantalla de inicio"**
6. Confirma tocando **"Instalar"**
7. ¡Listo! La app aparecerá en tu pantalla de inicio

### Método 2: Desde el Navegador Predeterminado
1. Abre tu navegador (Chrome, Firefox, Samsung Internet)
2. Visita: `http://localhost:3000`
3. Busca el **banner de instalación** que aparece en la parte superior
4. Toca **"Instalar"** o **"Añadir"**
5. Confirma la instalación

### Método 3: Acceso Directo (Si no aparece opción de instalación)
1. Abre el navegador y visita la web
2. Toca el **menú de tres puntos** (⋮)
3. Selecciona **"Añadir a pantalla de inicio"**
4. Edita el nombre si lo deseas
5. Toca **"Añadir"**

## 🚨 Solución de Problemas

### No aparece opción de instalación
1. **Actualiza Chrome** a la última versión
2. **Limpia caché** del navegador
3. **Reinicia** el dispositivo
4. Verifica **conexión a internet**
5. Intenta con **otro navegador**

### La app no funciona offline
1. **Abre la app** con conexión al menos una vez
2. Espera a que **cargue completamente**
3. Cierra y vuelve a **abrir la app**

### Icono no aparece en pantalla de inicio
1. **Busca en el cajón de apps**
2. **Reinicia** el dispositivo
3. Verifica **permisos de instalación**
